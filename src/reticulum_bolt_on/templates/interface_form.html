TCP Server: let others connect inward

Remote node → This node

Choose a local Listen IP and Listen Port, ensure clients can reach it, and configure matching IFAC on both sides when enabled. Tailscale peers must be in the same tailnet and permitted by policy; public Internet use requires external reachability separately.

Creating a TCP Server does not configure your router, firewall, Tailscale, or public DNS.

0.0.0.0 listens on all IPv4 interfaces; a LAN IP listens only on that LAN address; a Tailscale 100.x.x.x address listens only on Tailscale. Do not normally enter a public Internet IP here.

One IP may host several TCP servers when each uses a different port: Public Users 4242, Trusted Backbone 4243, Testing 4244. These are examples, not enforced assignments.

TCP Client: connect outward to another node

This node → Remote server

Target Host is the remote server’s reachable address or hostname. Target Port must match the remote server’s Listen Port. IFAC values must match the remote server exactly when enabled.
